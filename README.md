# YCDI website with a light content build (Stage 1: Blog and Gallery)

This keeps your existing site exactly as it is and adds a small build that generates
the Blog and Gallery from simple content, editable at `/admin`. No page design is
changed. Your other pages are copied through untouched.

## How the pieces fit

- Your existing pages now live in `/src` (unchanged) and are copied to the output as-is.
- The Blog, each blog post, and the Gallery are generated by Eleventy from Markdown in
  `/src/blog`.
- `/admin` is Sveltia CMS. Staff log in with GitHub and edit content. It commits to this
  repo; Netlify rebuilds automatically on every commit.
- GitHub stays the single source. Netlify stays the host. No Git Gateway.

## What builds to what

- `src/blog/*.md`  ->  `blog-<name>.html` (same URL pattern as before)
- `src/blog.njk`   ->  `blog.html`
- `src/gallery.njk`->  `gallery.html` (pulls every photo ticked "Show in main gallery")
- everything else in `src/` (your 14 pages, styles.css, assets)  ->  copied unchanged

## One-time setup checklist

### 1. Put these files in the repo
Replace the repo contents with this project. Your pages are unchanged, they now sit in
`/src`. Commit and push. (Netlify settings in step 3 tell it to build.)

### 2. GitHub
- Add each staff editor as a repository collaborator (Settings -> Collaborators).
- Create a GitHub OAuth App (github.com/settings/developers -> New OAuth App):
  - Homepage URL: your site URL
  - Authorization callback URL: `https://YOUR-SITE/callback`
  - Copy the Client ID and generate a Client Secret.

### 3. Netlify
- Build command: `npm run build`
- Publish directory: `_site`
- Functions directory: `netlify/functions`
- Environment variables: `NODE_VERSION=20`, `GITHUB_CLIENT_ID=...`, `GITHUB_CLIENT_SECRET=...`
- Deploy.

### 4. Point the CMS at your login
In `admin/config.yml`, set `base_url` to your site URL (already set to the netlify.app
address). The `/auth` and `/callback` handlers run on Netlify.

### 5. Test /admin
Visit `https://YOUR-SITE/admin`, click Login with GitHub, approve once. You should see
the Blog and Gallery editor.

### 6. Publish your first post
New post -> add title, author, date, category, excerpt, a featured image, write the body,
add gallery photos and tick "Show in main gallery" on the ones for the Gallery page,
leave Published ticked, Save/Publish. Netlify rebuilds in about a minute. The post
appears on `/blog`, its photos on `/gallery`. Untick Published to keep a draft.

## When you move to the custom domain
Internal links and images are relative or built from Netlify's own site URL, so they do
not break. Two small updates: set the GitHub OAuth App callback to
`https://your-domain/callback`, and set `base_url` in `admin/config.yml` to the new
domain. That is all.

## Local preview (optional, for a developer)
`npm install` then `npm run dev`, open the printed local address.
